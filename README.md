# Jabir Adem — Personal Portfolio

A responsive, bilingual static portfolio built with plain HTML, CSS, and JavaScript. It has no build step, package manager, or server requirement.

## Preview locally

Open `index.html` in a browser. For the closest match to a hosted site, serve this folder with any static file server.

## Deploy for free

### GitHub Pages

1. Create a GitHub repository and upload the contents of this folder, keeping the `assets` folder and image files in their current locations.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site and open the URL shown in the Pages settings.

### Netlify

1. Sign in to Netlify and choose **Add new site → Deploy manually**.
2. Drag this project folder into the deployment area, or connect its GitHub repository.
3. Leave the build command empty and set the publish directory to the project root.

## Before sharing

- Check the published page on a phone and desktop.
- Confirm the profile photos and `assets/musab-archive-dashboard.png` load.
- The contact form uses `mailto:` and opens the visitor's email app; it does not store or send messages through a server.
- The Google Fonts stylesheet needs an internet connection. System font fallbacks are included.
